# Gleipnir project page

Static page for the Gleipnir technical report, served by GitHub Pages from
the `main` branch root. It links the paper, the code
([Jazhyc/gleipnir](https://github.com/Jazhyc/gleipnir)), the models, the
training data and the serving image.

- `index.html`: the page (no build step, no external scripts or fonts).
- `assets/ood_frontier.svg`: Figure 1 of the report, copied from
  `outputs/reports/gleipnir_v1_technical_report/assets/` in the main repo.

Open items: the Paper button and the BibTeX wait for the public report.
